# 6. รูปแบบการรายงานผล (บังคับทุกครั้งที่จบงาน)

ตอบเป็นภาษาไทย โค้ด คอมเมนต์ และชื่อตัวแปรเป็นภาษาอังกฤษ

ผู้อ่านคือผู้บริหารที่มีเวลาน้อย เขียนแบบเลขาฯ ของ CEO: **ทั้งรายงานไม่เกิน 12 บรรทัด** อ่านจบใน 30 วินาที
รูปแบบนี้ ("สรุป + ตารางเดียว") ใช้กับทุกโครงการ ตามลำดับนี้:

```
**ผล:** <คำตัดสินหนึ่งบรรทัด: เสร็จ/ไม่เสร็จ ใช้ได้/ใช้ไม่ได้ — ข่าวร้ายอยู่ตรงนี้> · **ต้องการให้ตัดสินใจ:** <ข้อ 1 ด้านล่าง | ไม่มี>

| รายการ | ผล | หลักฐาน |
|---|---|---|
| <แต่ละเรื่องที่ผู้ใช้สั่ง ใช้เลขข้อของผู้ใช้> | <ทำแล้ว / ไม่ได้ทำ / ใช้ไม่ได้> | <ผลรันย่อ: tsc 0 error · test 16/16 · HTTP 200 · ก่อน 7 → หลัง 0> |

**ข้อ 1:** <คำถาม + ตัวเลือก + ตัวที่แนะนำ ให้ตอบได้ในคำเดียว>
**สมมติฐาน:** <ค่าที่เลือกแทนผู้ใช้>
**ยังไม่ได้ตรวจ / ยังไม่ได้ทำ:** <อะไร + เพราะอะไร หนึ่งบรรทัด>
```

บรรทัด **ข้อ 1** / **สมมติฐาน** / **ยังไม่ได้ตรวจ** ใส่เฉพาะเมื่อมี แต่ถ้ามีสิ่งที่ไม่ได้ทำหรือไม่ได้ตรวจ ต้องเขียนเสมอ (ห้าม fallback เงียบ)

## กฎการเขียน

- ตาราง**เดียว** ไม่เกิน 6 แถว — รวมรายการย่อยเป็นแถวเดียว ห้ามแตกหลายตาราง ห้ามหัวข้อย่อย
- คอลัมน์ "หลักฐาน" ต้องมาจากผลรันจริง ย่อเป็นตัวเลข ห้ามแปะ log ทั้งก้อน
- งานเล็กที่ไม่มีอะไรให้เทียบ ไม่ต้องมีตาราง: บรรทัด **ผล** + หลักฐานในวงเล็บ ก็พอ
- ไม่เล่ากระบวนการ ไม่อธิบายวิธีคิด ไม่ทวนคำสั่ง ไม่มีคำเกริ่นหรือคำปิดท้าย
- รายละเอียด ตัวเลือกอื่น และเหตุผลยาวๆ ให้เมื่อผู้ใช้ถาม หรือเขียนลงไฟล์แล้วใส่ลิงก์
- ไฟล์ที่อ้างถึง ให้เขียนเป็น markdown link ที่คลิกได้ พร้อมเลขบรรทัดถ้ามี
- คำสั่งที่ผู้ใช้ต้องรัน ใส่ใน code block ภาษา `bash` แยกก้อนละหนึ่งคำสั่ง (ไม่นับใน 12 บรรทัด)

# 7. ทำเองให้จบ อย่าโยนขั้นตอนกลับไปให้ผู้ใช้

ถ้าทำเองได้ ให้ทำ อย่าเขียนคู่มือให้ผู้ใช้ไปกดเอง
สิ่งที่ทำเองไม่ได้จริงๆ ให้ใส่ในบรรทัด **ยังไม่ได้ทำ** พร้อมเหตุผลว่าทำไมถึงทำไม่ได้

# 8. ข้อจำกัดของ Windows (เครื่องนี้)

- `npx` `npm` และ `.cmd` shim อื่นๆ spawn ตรงๆ ไม่ได้ ต้องผ่าน shell
  หรือเรียก JS entry point ของ package ผ่าน `node` แทน
- heredoc ทำให้ backslash เพี้ยน — regex และ path ของ Windows ให้เขียนด้วย
  เครื่องมือแก้ไฟล์ ไม่ใช่ pipe สคริปต์เข้า bash
- ตั้ง `PYTHONIOENCODING=utf-8` ก่อนรัน Python ที่พิมพ์ภาษาไทย
- ไฟล์ต้นฉบับอาจเป็น UTF-16 ให้อ่านแบบเผื่อไว้แล้วแปลงเป็น UTF-8
