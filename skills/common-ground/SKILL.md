# Common Ground Architecture Reconciliation

Surface and document hidden assumptions about endpoints, state layers, file configurations, and database schemas before writing code.

## Instructions for Agent:
1. Examine the project workspace files, active frameworks, and libraries.
2. Outline the tech stack details, active conventions (e.g. Next.js App Router rules, Supabase configurations).
3. Display a list of assumptions and wait for user confirmation or corrections.
