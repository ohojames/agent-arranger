# `run_page_number` — Running number บน PDF ที่มีอยู่แล้ว

ปั๊มเลขลำดับควบคุมหน้า (เช่น `C001`–`C178`) ลงบน PDF ที่ส่งมา **โดยไม่แตะไฟล์ต้นฉบับ**
ใช้กับเอกสารข้อเสนอ/เอกสารประกวดราคาที่ต้องมีเลขกำกับทุกหน้า

## จุดที่พลาดกันบ่อยที่สุด — ทิศทางกระดาษ

สไลด์มักถูก export เป็นหน้า **แนวนอน** แล้วเอาไป **พิมพ์บนกระดาษแนวตั้งโดยหมุน 90°**
"มุมขวาบน" ที่ผู้ใช้เห็นบนกระดาษที่พิมพ์ออกมา **ไม่ใช่** มุมขวาบนของหน้าใน PDF

| กระดาษถูกหมุนอย่างไร | มุมบนกระดาษที่ผู้ใช้เห็น | ต้องปั๊มที่มุมไหนของหน้าใน PDF | หมุนตัวอักษร |
|---|---|---|---|
| ไม่หมุน (`TURN=none`) | ขวาบน | ขวาบน | 0° |
| หมุนทวนเข็ม 90° (`TURN=ccw`) | **ขวาบน** | **ขวาล่าง** | **−90°** |
| หมุนตามเข็ม 90° (`TURN=cw`) | ขวาบน | ซ้ายบน | +90° |

**ห้ามเดา** ถ้าโจทย์ให้รูปตัวอย่างมาเป็นกระดาษแนวตั้ง แต่ไฟล์ที่ได้เป็นหน้าแนวนอน
ให้ถามก่อน 1 คำถามว่าต้องการแบบไหน เพราะเลือกผิดแล้วเลขไปโผล่คนละมุมและตะแคง —
เสียเวลาแก้มากกว่าถาม ทางเลือกที่ต้องเสนอคือ

1. **คงหน้าแนวนอนเดิม หมุนเลขให้ตรงรูป** — เปิดใน PDF viewer จะเห็นเลขตะแคงมุมล่าง
   แต่พอพิมพ์/หมุนกระดาษแล้วอยู่ถูกตำแหน่งและอ่านแนวนอน (มักเป็นสิ่งที่ต้องการ)
2. **คงหน้าแนวนอนเดิม เลขแนวปกติมุมขวาบนของหน้า** — เปิดดูสวย แต่พิมพ์หมุนแล้วเลขไปมุมอื่น
3. **สร้างหน้า A4 แนวตั้งใหม่ วางสไลด์หมุน 90° พร้อมขอบกระดาษ** — ตรงกับรูปที่สุดถ้ารูปมี
   "ขอบกระดาษ" รอบสไลด์ แต่เปลี่ยนขนาดหน้า (เป็นงาน imposition คนละเรื่องกับการปั๊มเลข)

## ขั้นตอน

1. **สำรวจไฟล์ต้นทางก่อนเสมอ** — จำนวนหน้า ขนาดหน้า และค่า rotate
   อย่าเชื่อว่าไฟล์ที่ผู้ใช้ให้มาคือไฟล์ที่เราสร้างเอง ผู้ใช้มักแก้เอง/ตัดหน้าออกแล้ว
   ```bash
   SRC="<input.pdf>" node "<skill>/scripts/stamp-pdf.mjs" 2>&1 | head -3   # จะ error ถ้าไม่ครบ env
   ```
   หรืออ่านด้วย pdf-lib สั้น ๆ: `getPageCount()`, `getSize()`, `getRotation().angle`

2. **ตกลงตำแหน่ง** ตามตารางด้านบน (ถามถ้าไม่ชัด) และตกลงว่าหน้าแรกนับเป็นเลข 1 หรือข้าม

3. **ปั๊มเลข**
   ```bash
   SRC="<input.pdf>" OUT="<output.pdf>" PREFIX=C TURN=ccw CORNER=tr \
     node "<skill>/scripts/stamp-pdf.mjs"
   ```

4. **ตรวจ — ห้ามข้าม** อ่านเลขกลับออกมาจากไฟล์ผลลัพธ์ทุกหน้า ไม่ใช่แค่ดูว่าสคริปต์รันผ่าน
   ```bash
   OUT="<output.pdf>" PREFIX=C TURN=ccw CORNER=tr \
     node "<skill>/scripts/verify-stamp.mjs"
   ```
   ต้องได้ `pages failing the check: 0` และจำนวนหน้าเท่าต้นฉบับ

5. **ถ้า `TURN` ไม่ใช่ `none` ให้หมุนภาพ proof ดูด้วยตา** ก่อนบอกว่าเสร็จ
   ```bash
   python -c "from PIL import Image; im=Image.open('proof-001.png'); im.rotate(90, expand=True).save('sheet-001.png')"
   ```
   `rotate(90)` ของ Pillow = ทวนเข็ม (ใช้กับ `TURN=ccw`) · ใช้ `rotate(-90)` กับ `TURN=cw`
   แล้วเปิดดูว่าเลขอยู่มุมที่ตกลงไว้และอ่านแนวนอนจริง

6. **ส่งภาพ proof ให้ผู้ใช้ดู** พร้อมบอก path ไฟล์ผลลัพธ์และ SHA256

## ตัวเลือกของ `stamp-pdf.mjs`

| Env | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `SRC` / `OUT` | — | ไฟล์เข้า/ออก · **OUT ต้องไม่ใช่ SRC** สคริปต์จะหยุดถ้าซ้ำ |
| `PREFIX` | `C` | คำนำหน้า **ASCII เท่านั้น** |
| `START` | `1` | เลขของหน้าแรกที่ปั๊ม |
| `SKIP_FIRST` | `0` | `1` = ไม่ปั๊มหน้าปก แล้วเริ่มนับที่หน้า 2 |
| `DIGITS` | `3` | จำนวนหลัก เช่น `3` → `C001` |
| `SIZE` | `11` | ขนาดตัวอักษร (pt) |
| `MARGIN` | `20` | ระยะห่างจากขอบทั้งสองด้าน (pt) |
| `BOLD` | `1` | `0` = Helvetica ธรรมดา |
| `TURN` | `none` | `none` \| `ccw` \| `cw` — กระดาษถูกหมุนอย่างไรตอนอ่าน/พิมพ์ |
| `CORNER` | `tr` | `tr` \| `tl` \| `br` \| `bl` — มุมที่ผู้ใช้เห็น **บนกระดาษสุดท้าย** |
| `PLATE` | `0` | `1` = วางพื้นขาวจาง ๆ รองหลังเลข ใช้เมื่อมุมนั้นเป็นพื้นเข้ม |

## ข้อจำกัดที่ต้องบอกผู้ใช้

- **PREFIX เป็นภาษาไทยไม่ได้** สคริปต์ใช้ Helvetica (WinAnsi) และเครื่องนี้ไม่มี
  `@pdf-lib/fontkit` จึงฝัง TTF ไทยไม่ได้ — สคริปต์จะหยุดพร้อมข้อความ ไม่ปั๊มตัวอักษรเพี้ยนออกมา
- **หน้าที่ไม่มีขอบกระดาษ** (สไลด์เต็มหน้า) เลขจะพิมพ์ทับเนื้อหา ถ้ามุมนั้นพื้นเข้มให้ใช้ `PLATE=1`
- ไฟล์ผลลัพธ์ถูก re-save ทั้งฉบับ ขนาดอาจเปลี่ยนเล็กน้อย (ปกติเล็กลง) — รายงานตามจริง
- ถ้าต้องการ **หน้า A4 แนวตั้งพร้อมขอบ** นี่ไม่ใช่งานของ skill นี้ ต้องทำ imposition แยก

## ที่มาของ runtime

สคริปต์หา `pdf-lib`, `playwright`, `pdfjs-dist` จาก (ตามลำดับ)
`$NODE_MODULES` → `./node_modules` → `~/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules`
ถ้าไม่พบจะ **หยุดพร้อมบอกว่าหาที่ไหนไปแล้วบ้าง** ไม่ใช้ทางสำรองเงียบ ๆ

## กับดักบน Windows

- อย่าเขียนสคริปต์ผ่าน heredoc ของ bash — backslash และ regex จะเพี้ยน ใช้ Write/Edit tool
- path ภาษาไทยให้ใช้ PowerShell หรือ Node ตรง ๆ (Bash tool บางครั้งอ่าน path ไทยไม่ออก)
- `PYTHONIOENCODING=utf-8` ก่อนรัน Python ที่พิมพ์ภาษาไทย
