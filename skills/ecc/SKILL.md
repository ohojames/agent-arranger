# ECC Engineering Team Workflow

Run the full ECC multi-role pipeline to design, verify, write, and audit changes for a feature request.

## Instructions for Agent:
1. Initialize as a **Product Manager (PM)** to refine scope and build a clear checklist.
2. Step into **System Analyst (SA)** to review affected schemas, files, and state management.
3. Write clean, modular, and typed code as the **Lead Engineer**.
4. Act as the **Security Auditor / QA** to review vulnerabilities and verify syntax correctness.
